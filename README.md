# osCTRL 
osCTRL is a library used for monitoring and remote-controlling operating systems. It provides a set of tools and APIs that allow developers to interact with the OS, retrieve system information, and perform various control operations.

## Primary functions
- Command line Code Execution (ls, dir, pwd etc) 
- Screenshot (with cursor position)
- Keyboard (typing)
- Mouse movement (move, hover, drag)
- Mouse click (up, down)

## Other
- Audit logging and forwarding 
- Finding software (os, installed, running, etc)
- Code repository discovery
